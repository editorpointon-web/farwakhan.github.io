FARWA KHAN — PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract the ZIP file (if you received the ZIP).
2. Open index.html in Chrome, Edge, or another browser.

ADD YOUR PROFILE PHOTO
1. Put your chosen profile photo in this same folder.
2. Rename it exactly: profile.jpg
3. Refresh index.html in the browser.
   (If your photo is PNG, convert it to JPG first or update the filename in index.html.)

PERSONALIZE BEFORE PUBLISHING
- Replace your.email@example.com with your real email address (search in index.html).
- Replace the LinkedIn and Instagram links with your own profile links.
- Add your real design samples/projects to the Portfolio section.
- The portfolio currently uses placeholder project categories; it does not claim they are completed client projects.

ONLINE PUBLISHING
This is a static website. You can publish the folder using a static hosting service such as GitHub Pages, Netlify, or another web host. Upload the folder contents, including index.html and profile.jpg.
